# Repository license decision

The public repository currently has no `LICENSE`, `COPYING`, or `NOTICE` file. No license has been added; this is a decision for the project owner.

## Recommendation

If the goal is for recruiters and other developers to reuse, modify, and redistribute this portfolio project with minimal friction, MIT is the simplest fit; its terms permit reuse subject to retaining the copyright and permission notice ([SPDX MIT text](https://spdx.org/licenses/MIT)). Apache-2.0 is a reasonable alternative if its explicit patent license and patent-termination terms are desired ([SPDX Apache-2.0 text](https://spdx.org/licenses/Apache-2.0.html)). Keeping the repository without a license is also an option; it avoids making a choice now, but does not grant the public the standard rights that an open-source license provides.

## Exact owner decision

Choose one option before adding a license file:

1. **MIT** — permissive reuse with attribution and license notice.
2. **Apache-2.0** — permissive reuse plus an express patent grant and related terms.
3. **No license for now** — leave the source public but do not add a license.
4. **Another license** — provide the exact license name and any required notices.

The technical deployment and public replay gates do not depend on this decision. Do not generate or publish a `LICENSE` file until the owner selects an option.
